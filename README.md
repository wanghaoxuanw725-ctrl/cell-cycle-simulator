# 细胞周期同步化模拟实验

一个基于 HTML + CSS + JavaScript + SVG 的细胞周期同步化模拟演示。通过加入/去除胸腺嘧啶，模拟细胞在 G1/S 期被阻断以及去除药物后同步释放的过程。

## 功能特点

- 100 个细胞沿圆环轨道运动，分别处于 G1、S、G2、M 四个阶段
- 实时统计各阶段细胞数量
- 支持暂停/继续、重置、模拟速度调节
- 加入药物（胸腺嘧啶）后，细胞会在 G1/S 边界被阻断
- 去除药物后，被阻断的细胞同步解除停滞，继续完成细胞周期
- 细胞颜色随所处阶段变化，直观展示同步化效果

## 如何运行

直接用浏览器打开 `index.html` 即可。

## 操作说明

| 控件 | 作用 |
| --- | --- |
| ⏸ 暂停 / ▶ 继续 | 暂停或继续模拟 |
| ↻ 重置 | 恢复初始随机分布与状态 |
| 模拟速度 | 调节模拟运行速度（0 ~ 2 倍速） |
| 加入药物 | 模拟加入胸腺嘧啶，使细胞在 G1/S 边界阻断 |
| 去除药物 | 解除阻断，细胞同步进入 S 期并继续周期 |

## 文件结构

```
.
├── index.html    # 页面结构
```

## 技术要点

- 使用 SVG 绘制圆环轨道和细胞
- 使用 `requestAnimationFrame` 驱动动画
- 每个细胞拥有独立的角度、速度和径向偏移
- 药物加入时：
  - 已经在 S 期的细胞原地停滞
  - 其他细胞移动到 G1/S 边界后停滞
- 药物去除后，所有细胞的 `blocked` 状态解除，恢复运动

## 用途

适合用于高中生物学教学中演示细胞周期同步化的基本原理。
